## Описание проекта

Целью проекта является разработка нейронной сети для распознавания эмоций в текстовых сообщениях и исследование её практического применения в области маркетинга.  
Рассматриваются шесть базовых эмоций: **радость**, **грусть**, **любовь**, **гнев**, **страх** и **удивление**.

Проект включает:
- Анализ и предобработку текстовых данных;
- Реализацию и сравнение двух моделей: базовой (SVM + TF-IDF) и нейросетевой (BiLSTM);
- Подбор гиперпараметров с использованием Optuna;
- Комплексную оценку качества моделей по метрикам F1-score, Accuracy, ROC-AUC;
- Обсуждение возможностей применения модели в data-driven маркетинге.

---

## Используемые данные

Для обучения и тестирования моделей использован открытый датасет с [Kaggle](https://www.kaggle.com/datasets/nelgiriyewithana/emotions/data), содержащий **416 809** текстовых сообщений, размеченных по эмоциям.

Основные характеристики:
- Шесть классов эмоций;
- Отсутствие пропущенных значений;
- Наличие дисбаланса классов (особенно по эмоции «удивление»);
- Преимущественно короткие тексты (до 200 символов).

## Модели

### 1. Базовая модель
- **Алгоритм**: LinearSVC
- **Векторизация**: TF-IDF
- **Weighted F1-score**: 0.90

### 2. Нейросетевая модель
- **Архитектура**: Bidirectional LSTM (BiLSTM)
- **Особенности**:
  - Embedding-слой;
  - Два направления и два скрытых слоя;
  - Mean & Max Pooling;
  - BatchNorm + Dropout для регуляризации.
- **Гиперпараметры** подобраны с помощью **Optuna**.
- **Результаты на тестовой выборке**:
  - **Accuracy**: 0.94  
  - **Weighted F1-score**: 0.94  
  - **Macro F1-score**: 0.92  
  - **ROC-AUC**: 0.996–0.999 по всем классам
